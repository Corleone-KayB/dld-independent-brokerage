# DLD / Verification Guardrails

The product specification explicitly requires the platform to complement official DLD services rather than pretend to replace them.

UI wording:
- Verified against official DLD source
- Platform Verified
- Verification Pending

For official-source links, store them in configuration rather than scattering URLs throughout the application.

Never invent an API endpoint or claim live DLD access.

Where no authorized API exists in the development environment, provide an official verification link and clearly label the platform's own verification state.

Demo data must be labelled as demo/seed data where needed.
